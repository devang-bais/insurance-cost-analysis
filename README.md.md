# Insurance Cost Analysis — EDA

This project explores the insurance dataset using Python and pandas. It includes exploratory data analysis (EDA), data inspection, cleaning/preprocessing steps, categorical encoding, and visualizations where included in the notebook.

## Files
- `insurance.csv` — dataset file (upload your copy of the dataset here).
- `insurance_eda_colab.ipynb` — Jupyter/Google Colab notebook with the project code.
- `insurance_eda.py` — Python-script export of the notebook's code cells.

## Run in Google Colab
1. Upload `insurance_eda_colab.ipynb` to Google Colab.
2. Upload `insurance.csv` when the first notebook cell prompts you to choose a file.
3. Run the notebook cells from top to bottom, or choose **Runtime → Run all**.

## Run locally
Install the libraries used by the notebook, such as pandas, numpy, seaborn, and matplotlib. Place `insurance.csv` in the same folder as the script/notebook, then run the code.

## Notes
Make sure the dataset filename is exactly `insurance.csv`, or update the filename in the `pd.read_csv()` line.
